My Basketball Shooter Game:
A simple 2D web game where you charge up your shots to score hoops.

Play the Game: 
🏀 Play it right here!
https://kyanitethecreator.github.io/My-Basketball-Shooter-Game/

Quick Start:
You literally just click the link above. It runs right in your browser so you don't need to download anything. Just hold the charge button to build power, and let go to shoot.

What's in the game?
* Charge mechanic: Hold the button to shoot harder. Timing is everything!
* Score tracking: It keeps track of your score and how many shots you take so you can see your accuracy.
* No waiting: The ball resets right away so you can just keep spamming shots.

How to run it locally:
If you want to look at my code or mess around with it yourself:
1. Download or clone this repo to your computer.
2. You don't need to install any extra software or weird servers.
3. Just double-click the index.html file to open it in Chrome or whatever browser you use.

How it works:
This is literally my first-ever coding project! I made the game layout and the shooting loop from scratch. Because I'm a beginner and game physics are honestly pretty confusing, I used VS Code Copilot to help me out. It was super helpful for debugging when my ball would just fly off the screen or glitch out. It basically acted like a tutor to help fix my messy code so I didn't get stuck and give up.
